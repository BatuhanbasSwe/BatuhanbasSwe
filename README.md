## 🚀 Featured Projects

### 🧠 AI / Machine Learning

| Project | What it does | Stack |
|:--|:--|:--|
| 🔤 [**GrammarLens**](https://github.com/BatuhanbasSwe/GrammarLens) | Classifies English grammatical error types on a self-built dataset from UD English-EWT. Naive Bayes and CNN baselines vs. DistilBERT and DeBERTa-v3 (I built the transformer models). | Python · PyTorch · 🤗 Transformers |
